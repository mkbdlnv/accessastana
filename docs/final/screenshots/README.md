## Примечания

- Все десять скриншотов сделаны; карта, гексагоны и таблицы отрисованы, баннеров ошибок и индикаторов загрузки нет.
- `06_scenario_result.png`: точки новых поликлиник поставлены в густонаселённые и плохо обслуживаемые ячейки (≈ 71,479/51,094; 71,493/51,096; 71,429/51,058).
- Снимки 01–08 пересняты 16.11.2026 после двух исправлений интерфейса, найденных при первой съёмке: боковая панель расширена до 440 px, и таблица районов помещается целиком без прокрутки; в казахской версии числа теперь форматируются по нормам Казахстана (`206 759`, `0,67`). Ни один снимок не использует подмену стилей.
- Скорости зимних профилей на снимках соответствуют `config/seasons.yaml` после уточнения по Fossum & Ryeng (2021): 1,235 и 1,106 м/с.
